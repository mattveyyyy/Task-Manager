# Task Manager — менеджер задач

## Описание реализованного функционала

Task Manager — это простой и удобный инструмент для управления задачами на основе канбан-доски. Основные возможности приложения:

- Создание новых задач с указанием статуса и приоритета
- Редактирование существующих задач
- Перетаскивание задач между колонками (статусами) с помощью drag-and-drop
- Удаление задач
- Сохранение задач в `localStorage` для долговременного хранения данных
- Использование цветовой маркировки и визуальных тегов для удобного восприятия
- Адаптивный и современный интерфейс, построенный на Material UI

## Инструкция по запуску

1. **Клонируй репозиторий:**

```bash
git clone https://github.com/mattveyyyy/Task-Manager.git
cd Task-Manager
```

Установи зависимости:
```bash
npm install
```
или
```bash
yarn
```

Запусти проект в режиме разработки:
```bash
npm run dev
```
или
```bash
yarn dev
```

Открой в браузере:
Перейди по адресу 
```bash
http://localhost:5173
```

## Используемые технологии
React — библиотека для построения пользовательских интерфейсов

TypeScript — строгая типизация для надежного кода

Vite — быстрый инструмент для сборки и разработки

MUI (Material UI) — набор готовых UI-компонентов

@hello-pangea/dnd — drag-and-drop между колонками

CSS Modules — модульные стили

Lucide-react — легкие SVG-иконки

Redux Toolkit — управление состоянием приложения

localStorage — долговременное хранение задач в браузере

ESLint + Prettier — проверка и форматирование кода

Path Aliases — удобные импорт-пути (например, @entities, @features)

## Описание архитектуры
Проект построен с использованием архитектуры Feature-Sliced Design:

entities — бизнес-логика и модели задач (tasks), включая Redux slice и типы

features — функциональные части с UI для управления задачами (например, формы для создания/редактирования)

widgets — сложные компоненты и контейнеры (например, канбан-доска TaskBoard)

pages — компоненты страниц (EditTaskPage, NewTaskPage, TaskBoardPage) с маршрутизацией

shared — повторно используемые UI-компоненты и утилиты (например, кнопки)

app — конфигурация приложения, стора, темы и корневой компонент App

Это позволяет поддерживать код чистым, легко масштабируемым и удобным для командной работы.
